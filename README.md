# Health Awareness Campaign
#### A web application focused on encouraging individuals to live a healthy lifestyle through awareness. **Version 1.0 – April 2025**  
#### By **Valentine**

## Description
“Health Awareness Campaign” is a web application that enables individuals to:

- **Track daily health activities** (via an interactive checklist)  
- **Receive a weekly health tip** to stay motivated  
- **Submit questions or feedback** through a dedicated feedback form  
- **Access contact details** for qualified doctors and specialists in their area  

This empowers users to make informed decisions about their well-being and maintain a healthier lifestyle through ongoing awareness and engagement.

## Setup/Installation Requirements
- No installation required.
- Simply browse the files on your local machine using a browser.
